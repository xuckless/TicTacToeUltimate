# ResultCard

Post-game result: outcome headline, rating delta and next actions.

- **Consumer provides:** the outcome (win, loss, abort), the winner's piece (it colors the headline), the old and new rating, and whether the match was competitive.
- Rematch appears **only for non-competitive matches**, to prevent win-trading. Analyze opens the perfect-play review, which is behind a rewarded ad.
- No interstitial ad shows here directly; the interstitial counter runs on the next "New match" tap.
